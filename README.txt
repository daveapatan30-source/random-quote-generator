DESCRIPTION:
A web application that retrieves random quotes and displays their authors using a public API.

API NAME:
DummyJSON Quotes API

API ENDPOINT:
https://dummyjson.com/quotes/random

DOCUMENTATION:
https://dummyjson.com/docs/quotes

FILES:
index.html - Portfolio homepage
app.html - Random Quote Generator application
styles.css - Website design and styling
script.js - API integration and application logic
README.txt - Project documentation
profile.jpg - Profile photo

HOW TO RUN:
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if needed.
3. Right-click index.html and select Open with Live Server.
4. Click Open My Application.
5. Click Generate New Quote to retrieve a random quote.

REQUIREMENTS:
An internet connection is required to retrieve quotes from the API.
